《勇者传说》是一款像素风横版动作冒险 Demo：主角从营地出发，穿越森林与洞穴，一路战斗、攀爬、成长，最终在洞穴深处迎战三阶段的守护者。

## 核心玩法

- **扎实的动作手感**：三段普攻连击（带突进与连击输入窗口）、翻滚无敌帧、土狼时间与跳跃缓冲、空中攻击保留惯性、受击无敌帧与击退；命中带顿帧与震屏强化打击感。
- **攀爬与探索**：蹬墙跳、墙面攀爬与攀缘边缘，由「攀岩手」能力解锁；关卡纵向多层，结合下跳木平台、尖刺陷阱与隐藏区域。
- **轻量生存资源**：体力驱动翻滚与冲刺，酒瓶回血（Q 键）；首次受伤自动出现治疗提示，红宝石戒指可提升最大血量。
- **新手引导逐步解锁**：营地教程按「AD 移动 → J 攻击 → SHIFT 翻滚 → K 跳跃」分阶段教学，引导期间暂停游戏、屏蔽多余输入，读档后自动跳过已完成阶段。

## 设计亮点

1. **能力即内容**：攀爬不是起点技能而是流程奖励，教程把「解锁」变成可感知的成长节点。
2. **Boss 战有演出节奏**：洞穴僧侣以冥想开场（镜头运镜 + 锁定操作），血量 70% 解锁特殊攻击、50% 解锁空中攻击，配三阶段 AI、护甲机制与独立 Boss 镜头。
3. **场景状态持久化**：敌人存活与存档点状态按场景记忆，往返场景不重置进度；死亡只重载当前场景小怪，存档点系统跨场景生效。
4. **判定层清晰**：物理层区分地形 / 角色 / 敌人 / 受击盒，Hitbox 与 Hurtbox 解耦，音效、顿帧、震屏等打击反馈统一处理。

## 当前 Demo 内容

- **完整流程**：营地（新手教程）→ 森林 → 洞穴一层 → 洞穴二层 → Boss 房；另有训练假人、宝箱、方尖碑、存档石与胜利传送门。
- **多种小怪原型**：野猪、水晶敌人、蜜蜂 / 蜗牛等，各自带巡逻与追击行为。
- **Boss 三阶段战**：岩石投掷、三段近战连击、地刺与空中俯冲，击败后触发通关结算画面。
- **系统齐全**：4 槽位存档 / 读档、暂停与音量设置、死亡重生、胜利结算。

## 技术实现

- **引擎**：Godot 4.7 + GDScript，2D 像素（内部 384×216，画布拉伸）。
- **架构**：Player 状态机 + 独立敌人脚本、伤害 / 受击盒类、Game / SoundManager 单例、场景状态 to_dict / from_dict 持久化。
- **数据与验证**：JSON 存档与音频配置，headless 可跑的自动化探针脚本（伤害、体力、喝酒、击退等）辅助调参。
