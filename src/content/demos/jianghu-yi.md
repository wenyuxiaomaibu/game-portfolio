《江湖弈》是一款武侠题材的卡牌构筑 Roguelike（爬塔式结构），也是我以「策划 / 设计向」为目标制作的求职 Demo。玩家从江湖无名之辈起步，在「出招推进」与「蓄力积内力」之间运筹取舍，一路打到一代宗师。

## 核心玩法

- **内力双资源**：体力每回合恢复至上限，驱动多数招式；内力跨回合保留、不归零，是杀招的燃料。每回合都在「当下收益」与「未来收益」之间取舍——这回合是连打压制，还是防守蓄力、为下回合爆发做准备。
- **敌人意图全程可见**：先看意图再决策，失败可以归因（「我贪了」或「我算错了」），拒绝随机斩杀式的不可解释失败。
- **武侠化状态**：护体（格挡）、破绽（增伤）、内伤 / 流血（持续伤害）、点穴（削弱），机制对齐成熟卡牌设计，命名贴合武侠题材。
- **三选一构筑**：战后三选一武学，配合商店买牌 / 删牌、休息点回血或升级，逐步成型 20~30 张的牌组。

## 设计亮点

1. **差异化设计核**：内力双资源不是「第二种费用」，而是跨回合的资源管理与爆发兑现，让「攒 vs 放」成为每回合的真实决策。
2. **门派流派差异**：三个门派三种节奏——混元宗内力爆发流、疾风门低费快攻连打流、铁衣谷护体防守反击流，开局三选一，各配 7 张门派专属卡。
3. **数值与流程可验证**：全项目按「假设 → 原型 → 验证」推进，P0 优先验证最危险假设（内力是否创造新决策），后续每阶段都有自动化测试与模拟探针把关（14 个模块测试 + 战斗 / 通关双探针，分门派统计胜率）。
4. **文档即作品集**：12 份设计文档覆盖定位、核心玩法、系统、数值、内容规划、技术架构、里程碑与验证，假设透明、逻辑闭环。

## 当前 Demo 内容

- **双层随机地图**：每列双候选路线（上=风险路线，下=平稳路线），节点包含战斗、精英、事件、商店、休息，末列为 Boss；每把随机生成，同种子可复现。
- **敌人三原型**：快攻压制、蓄力爆发、持续消耗；机制化精英（毒砂双煞、破甲刀客、点穴狂徒）与三阶段 Boss，组合考验出招节奏、意图预判与状态处理。
- **心法与节点**：心法（对应遗物位）提供常驻规则变化；事件、商店、休息均为「有代价的选择」而非纯赠予。

## 技术实现

- **引擎**：Godot 4.7 + GDScript，PC（鼠标优先，1280×720）。
- **数据驱动**：卡牌、敌人、事件、心法全部 JSON 化，效果以数据描述，代码只做「解释器」，新增内容不碰战斗主流程。
- **架构**：战斗逻辑与 UI 表现分离、单例服务 + 信号通信、全局可复现随机（种子）；headless 命令行即可运行全部测试与模拟探针。
- **开发方式**：TDD + Godot headless 自动化测试，模拟探针批量跑局统计胜率辅助数值调参。
